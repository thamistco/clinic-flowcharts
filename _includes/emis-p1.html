    66 chart prompt sets + 8 source-only local sets

    One blank prompt set for every restored clinical chart and support page, plus eight source-only East Sussex MSK local reference sets (area-specific publisher references, not restored charts). Topics are condition-specific, but no findings, diagnoses, medicines, doses or codes are preselected. These are plain-text build aids, not installable EMIS templates.

    Review with the practice template lead. Use active selections only, verify codes locally and test output on a practice-approved test patient before activating. Do not paste a blank prompt set into a patient record and leave it uncompleted. Each template was rewritten on 21–23 November 2026 from the checked chart it mirrors and the NICE, NHS or East Sussex MSK sources listed below it (shown on the page, not copied), with an automated check that each question and safety-net line appears in its cited source. Each clinical template includes a short background block (drug allergy status; current medicines; ideas, concerns and expectations). Where it clearly cuts the number of answers, a quick version (red flags and plan) is offered. This is not clinical validation.
